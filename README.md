# Alchemy Factory Builder

Plans production for [Alchemy Factory](https://store.steampowered.com/app/3591710/Alchemy_Factory/), generates compact, stackable factory modules from the plan and exports them as in-game blueprints. Works on phones as well as on desktop.

**Live:** https://alchemy-factory-plan-tool.vercel.app/

- **Planner**: pick targets, research levels, fuel and fertilizer. A linear program chooses recipes and rates (cheapest raw materials, simplest machines), including self-made fuel and fertilizer loops and cauldron mixes.
- **Build**: turns the plan into modules (towers, belts, splitters, pipes, heaters, starter box) and exports a blueprint file the game loads.
- **Codex**: items, devices, cauldron and advanced cauldron mixes ranked by a builder score, and a Paradox Crucible calculator.

## Development

Needs [Bun](https://bun.sh).

```bash
bun install
bun run dev      # http://localhost:3000
bun test
bun run typecheck
```

## Game data

`data/building-footprints.json` and `data/building-unlocks.json` are generated from the game files by `tools/extract-game-data` (see its README). `data/items.json`, `data/recipes.json` and `data/devices.json` hold the game's item and recipe values; they will be regenerated by the same extractor. Item and building icons in `public/game-icons/` are exported from the game by the same extractor. Items without an exported icon get our own symbol (lib/itemGlyph.ts).
